# 📋 Todo App

**Dincharya** is a simple and efficient Todo application designed to help users organize their daily tasks and stay productive. Built with **HTML, CSS, and JavaScript**, the app provides an intuitive interface for managing tasks with ease.

## ✨ Features

* ✅ Add new tasks
* 📝 Edit existing tasks
* 🗑️ Delete completed or unwanted tasks
* ✔️ Mark tasks as completed
* ⚡ Fast and lightweight
* 📱 Responsive and user-friendly design

## 🔄 How It Works

1. ➕ Add a task to your list.
2. 📋 View all pending tasks.
3. ✔️ Mark tasks as completed when finished.
4. 🗑️ Remove tasks that are no longer needed.
